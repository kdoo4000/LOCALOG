# LOCALOG

**여행, 일상처럼.**

LOCALOG는 여행자의 사진과 실제 방문 동선을 바탕으로 로컬 여행 루트를 만들고 공유하는 여행 플랫폼입니다. 유명 관광지만 따라가는 여행이 아니라, 누군가의 하루를 따라 걸으며 동네의 카페, 서점, 식당, 골목, 바다, 야경을 자연스럽게 발견하는 경험을 제공합니다.

LOCALOG의 핵심은 **현지인의 숨은 하루를 여행자의 완벽한 하루로 바꾸는 것**입니다.

## 서비스 소개

여행지를 검색하면 수많은 광고, 별점, 추천 목록이 쏟아집니다. 하지만 실제로 그 지역을 어떻게 걸어야 하는지, 어떤 순서로 방문하면 좋은지, 하루를 어떻게 보내면 자연스러운지는 알기 어렵습니다.

LOCALOG는 이 문제를 **사람이 직접 다녀온 루트**로 해결합니다.

사용자는 자신이 찍은 여행 사진을 올리고, 앱은 사진의 촬영 시간과 위치 정보를 바탕으로 방문 순서를 정리합니다. 이렇게 만들어진 루트는 다른 여행자가 검색하고 다운로드해 자신의 일정으로 편집할 수 있습니다.

## 핵심 가치

- **광고보다 실제 동선**
  여행자가 직접 다녀온 순서와 장소를 기반으로 루트를 구성합니다.

- **별점보다 맥락**
  단일 장소 리뷰가 아니라 하루 전체의 흐름을 보여줍니다.

- **관광보다 로컬리티**
  유명 명소뿐 아니라 카페, 골목, 서점, 식당처럼 일상적인 장소를 함께 담습니다.

- **기록보다 자동 정리**
  여행 사진의 시간과 위치 데이터를 활용해 방문 타임라인을 자동으로 만듭니다.

- **소비보다 재가공**
  다른 사람이 만든 루트를 그대로 쓰는 데서 끝나지 않고, 내 일정에 맞게 편집할 수 있습니다.

## 주요 사용자

LOCALOG는 이런 사람들을 위한 앱입니다.

- 처음 가는 도시에서 믿을 만한 하루 코스를 찾고 싶은 여행자
- 관광지만 도는 여행보다 동네의 분위기를 느끼고 싶은 사람
- 친구나 동행자와 여행 일정과 지출을 함께 정리하고 싶은 사용자
- 자신이 다녀온 좋은 코스를 다른 사람에게 공유하고 싶은 여행자
- 외국인처럼 낯선 지역을 여행하지만 현지인의 동선을 따라가고 싶은 사용자

## 앱에서 할 수 있는 일

### 로컬 루트 찾기

사용자는 도시, 키워드, 태그를 기준으로 다른 여행자가 만든 로컬 루트를 찾을 수 있습니다.

예를 들어 다음과 같은 루트를 탐색할 수 있습니다.

- 서울 중구 당일치기 로컬 코스
- 부산 여름 바다 루트
- 경주 고궁과 야경 산책
- 서점과 카페를 따라 걷는 반나절 코스
- 현지인이 자주 가는 맛집 중심 루트

각 루트는 단순 장소 목록이 아니라 방문 순서, 예상 소요 시간, 태그, 작성자, 다운로드 수, 추천 비율을 함께 보여줍니다.

### 루트 다운로드와 편집

마음에 드는 루트는 다운로드해 자신의 여행 일정으로 가져올 수 있습니다.

다운로드한 루트는 그대로 사용할 수도 있고, 여행 일정에 맞게 장소 순서를 바꾸거나 일부 장소를 삭제하고 새로운 장소를 추가할 수 있습니다. LOCALOG는 남의 여행을 복사하는 앱이 아니라, 좋은 루트를 내 하루에 맞게 재구성하는 앱입니다.

### 사진으로 루트 만들기

여행을 다녀온 뒤 여러 장의 사진을 선택하면, LOCALOG는 사진의 메타데이터를 읽어 방문 타임라인을 만듭니다.

앱은 사진에서 다음 정보를 확인합니다.

- 촬영 시간
- 위도와 경도
- 날짜별 사진 그룹
- 방문 순서
- 위치 기반 장소 후보

사용자는 자동으로 정리된 타임라인을 확인하고, 장소명을 보정하거나 메모를 추가해 하나의 로컬 루트로 만들 수 있습니다.

### 영수증 정산

여행 중 받은 영수증을 업로드하면, 앱은 OCR 결과를 바탕으로 구매 품목과 가격을 보여줍니다.

사용자는 품목을 수정하고, 친구나 동행자별로 금액을 나눌 수 있습니다. 외국인 여행자를 위한 예상 VAT 환급액도 함께 확인할 수 있도록 설계되어 있습니다.

## LOCALOG가 지향하는 여행

LOCALOG가 제안하는 여행은 빠르게 많이 보는 여행이 아닙니다.

대신 이런 여행을 지향합니다.

- 아침에 동네 카페에서 시작하는 여행
- 지도에 크게 표시되지 않는 작은 서점을 들르는 여행
- 현지인이 자주 가는 식당에서 점심을 먹는 여행
- 골목과 공원을 천천히 걷는 여행
- 밤에는 야경이나 바다를 보며 하루를 마무리하는 여행

LOCALOG는 여행지를 소비하는 방식보다, 누군가의 하루를 따라가며 지역의 감각을 발견하는 방식을 중요하게 생각합니다.

## 주요 화면

- **Home**
  현재 여행지, 추천 루트, 주요 기능 바로가기를 보여주는 첫 화면입니다.

- **Search**
  도시, 키워드, 태그를 기준으로 로컬 루트를 찾는 화면입니다.

- **Upload**
  여행 사진을 선택하고, 사진의 시간과 위치를 바탕으로 루트를 만드는 화면입니다.

- **Map**
  주변 장소와 루트의 위치를 지도 중심으로 확인하는 화면입니다.

- **Profile**
  다운로드한 루트, 업로드한 루트, 설정을 관리하는 화면입니다.

## 로컬 실행 설정

네이버 지도 API ID는 Git에서 제외되는 `config/local.json`에 저장합니다.
처음 한 번 `NAVER_MAP_CLIENT_ID` 값을 설정한 뒤 다음 명령으로 실행합니다.

```powershell
.\tools\run_web.ps1
```

웹 포트를 지정하려면 `-WebPort 8080`을 추가할 수 있습니다. VS Code에서는
`LOCALOG (Chrome, local config)` 실행 구성을 선택하면 같은 설정이 자동으로
적용됩니다. 공유 가능한 키 목록은 `config/local.example.json`에서 관리합니다.
