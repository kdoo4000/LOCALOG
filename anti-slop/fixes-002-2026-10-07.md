# UI 디자인 수정 결과 · 2026-10-07

[디자인 검증 보고서](audit-002-2026-10-07.md)의 5개 항목과 사용자가 지적한 홈 배경 무늬를 수정했다.

## 수정

1. **로그 상세 제목 가림:** 배경 헤더를 본문과 같은 스크롤 흐름으로 옮겼다. 고정 화면 비율 높이와 초기 자동 스크롤을 제거하고 제목·작성자·태그 높이에 따라 헤더가 늘어나도록 했다. 대표 제목과 작성자 정보의 줄 수 제한도 제거했다. 사진 위의 어두운 배경은 내용 전체의 대비를 보장하도록 유지했다.
2. **장소 상세 대비:** 상단 제목과 뒤로 가기를 흰색으로 명시했다. 접힌 앱바는 진한 파란색을 사용하며 사진 상단에도 어두운 배경을 적용했다. 펼침·접힘 모두 흰색 전경을 유지하는 방식으로 해결했다.
3. **정산 요약:** 공통 `AppMetricStrip`이 항목당 유효 너비와 글씨 배율을 보고 세로로 재배치한다. 세로 배치에는 기존 제목 크기 17을 사용해 큰 글씨에서도 긴 금액을 읽기 쉽게 표시한다. 영수증 정산·내 여행·지출·사진 결과의 공통 수정이다.
4. **홈 제목:** 대표 여행 제목의 2줄 생략을 제거했다. `함께 떠나는 부산 여행`이 320×720/200%에서도 전체 표시된다.
5. **태블릿 사진·버튼:** 로그 카드 너비를 기존 읽기 너비 680으로 제한하고 사진은 약 1.86:1 비율을 유지한다. 여행 생성/수정 버튼의 최대 너비는 중앙 폼의 내부 너비 632에 맞췄다.
6. **홈 무늬:** 사용자 요청에 따라 새로 넣었던 경로 아이콘을 제거하고, Git 원본의 반투명 흰색 원과 라임색 링을 복원했다. 원의 위치(right -54, top -72)·크기 190·투명도 .08, 링의 위치(right 22, bottom -70)·크기 130·선 두께 24·투명도 .35를 원래 값 그대로 사용한다. 공통 여행 배너에 적용된다.

새 기능·의존성·디자인 체계는 추가하지 않았다.

## 검증

- 전체 자동 검사: **146개 통과**, 구성 조건에 따른 로그인 검사 5개 제외.
- 로그인 화면 검사: 로컬 가짜 응답으로 별도 실행해 **5개 통과**. 운영 서버에 연결하지 않았다.
- 합계 **151개 통과**.
- 이후 원래 홈 무늬를 복원한 뒤 화면 크기별 검사·키보드 검사 **5개를 다시 실행해 통과**했고 캡처도 갱신했다.
- 정적 검사: 오류·경고 없음.
- 로그 상세 제목이 화면 안에 있고 본문보다 위에 위치하는지 4개 화면 조건에서 확인하는 검사를 추가했다.
- 320×720/200%에서 `12,345,678원`이 한 줄로 표시되고 다음 요약 항목과 겹치지 않는 검사를 추가했다.
- 화면 캡처는 390×844/100%, 320×720/200%, 844×390/200%, 1200×900/100%에서 다시 생성했다. 기존 캡처 기능이 모든 크기를 저장하도록 수정했으며 임시 검사 파일은 제거했다.
- `git diff --check` 통과. 기존 파일의 줄바꿈 변환 안내 외 공백 오류는 없다.
- 웹 빌드 성공. 예시 모드 구성으로 `build/web`을 생성했다. 배포는 수행하지 않았다.
